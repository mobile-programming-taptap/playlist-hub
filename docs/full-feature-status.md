현재 장르 처리는 재즈·클래식·힙합·R&B·전자 음악·블루스·메탈 조건을 보존한다. 해당 조건의 곡이 없으면 새 추천은 0곡이며, 직접 유지한 곡은 새 조건과 별도로 남긴다. AI가 태그 목록 밖의 장르를 반환할 때는 기존 `tags`의 `unsupported_genre`로 보존하고 다른 장르로 채우지 않는다. 기본 모드의 단어 사전 밖 장르 해석은 AI에 의존한다. 서버는 내부 언어 지정 여부를 검증·제거하고 명시하지 않은 언어는 이전 조건 또는 빈 값으로 보정한다. 제외 근거가 없는 미지원 장르의 제외 응답도 긍정 조건으로 보정하며, 현재 snapshot과 초기화 이후의 직접 요청을 구분한다. 서로 다른 미지원 장르의 긍정·부정이 같은 표식으로 충돌해도 긍정 조건을 보존한다. 긍정 미지원 장르와 모든 지원 장르 제외가 함께 나온 응답에만 직접 요청·이전 snapshot의 제외를 적용하며, 명시한 피아노·기존 조건·초기화를 보존한다. `exclude/avoid/without`도 알려진 태그 바로 앞의 제외로 해석하고 부분어는 부정으로 오인하지 않는다. 영상 길이 0/-1은 미상이며, 길이를 알면 종료 시각보다 작은 시작 시각만 허용하고, 미상이면 시작 시각의 6시간 포함 상한을 검증한다.

## 보관된 검사 근거와 재검증

아래 통과 기록은 각 파일의 검사 시각과 APK/JAR 해시를 기준으로 한다. 현재 APK `52bbb2c2…0833a0ef`는 매칭 상태 안내와 영상 끝 시각 차단을 포함하며 Android 34개 검사를 통과했다. 현재 JAR `55459b52…ad235930`는 H2와 PostgreSQL 각 11개 검사와 재시작 보존 검사를 통과했다. 직전 JAR `ef095d41…197271b3`의 실제 OpenAI 9회 기록은 해당 빌드의 근거로 보존하며, 현재 추천 API·OpenAI 클래스·core JAR·카탈로그가 그 빌드와 바이트 단위로 같음을 [확인했다](../output/checks/recommendation-bytecode-current.json). 실제 AI 호출을 새로 실행한 기록으로 바꾸지 않는다. 이전 실패 기록과 이전 빌드의 기록도 각 파일의 해시 범위로 보관한다.

- Android 화면 검사: APK `52bbb2c2…0833a0ef`로 API24 기본·대화 13개 + Hub 3개, API37 기본·대화 15개 + Hub 3개, 합계 34개 통과. Hub 검사는 OS 연결 복귀·화면 재생성·초기 복귀, 계정·변환·공개·별도 로그인 세션의 반응/목록 변경 후 복귀 갱신을 확인한다. 추천이 진행되는 동안 회전 없이 앱을 배경·복귀시켜 반응·저장 상태가 끝난 뒤 정확히 한 번 갱신되는지도 확인했다. 가져오기·곡 수정·후보 선택·제외·전송 확인·부분 실패 재시도·결과 복원, 수정 시각의 실제 외부 Intent 및 음수/범위 초과 차단을 검사했다. 영상 길이 0에서 60초 열기, 21601초 열기/저장 거절, 90초 수정·저장·재열기·화면 재생성 후 보존도 확인했다. 외부 서비스 응답은 모의 서버이며 실제 플랫폼 OAuth 승인은 포함하지 않는다. 저장·복사 후 명시적인 ‘내 목록으로’는 실제 목록 ID와 곡 상세를 열며, ‘계속 보기’와 일반 뒤로 가기는 이전 화면을 유지한다. 공개 검색 100자 입력·복원·초과 미전송도 확인했다. 매칭 화면의 일치 후보·버전 확인·조회 전·찾지 못함과 선택·제외 표시, 다음 페이지 조회·화면 재생성 후 보존을 확인했다. 일치 점수만으로 전송을 승인하지 않으며 직접 선택해야 한다. 알려진 영상의 종료 시각은 열기·저장·수정에서 거절한다. 앱 검사는 현재 JAR의 키 없는 임시 서버를 사용했다. 실제 OpenAI 9회는 직전 JAR에서 호출한 기록이며, 현재 추천 관련 파일이 그 빌드와 바이트 단위로 같음을 별도로 확인했다. - 실제 OpenAI: [실제 호출 근거](../output/checks/openai-full.json). `2026-10-03T21:13:00.762488+00:00`, 이전 JAR `ef095d41…197271b3`에서 9회 모두 OpenAI 모드로 통과했다. 최초 신나는 음악 8곡은 언어 미지정, 영어 팝·연주곡 제외로 변경한 결과 7곡은 유지 곡 포함. 가사 없는 재즈와 미지원 Gregorian chant는 0곡, 서로 다른 미지원 장르를 지정/제외한 요청도 불필요한 제외 없이 0곡을 안내했고, 그 결과와 단독 장르 결과 각각에서 팝으로 바꾸면 언어 미지정 7곡으로 복구했다. 영어 피아노 제외 요청과 후속 팝 요청에서도 피아노 제외를 유지해 7곡을 확인했다. 허용 곡만 반환, 유지곡 보존·임시 제외곡 부재·반응 데이터 변경 없음·검사 계정 삭제를 확인했다. 자연어 전체와 임의 장르의 품질 검증을 의미하지 않으며 사전 밖 의미 해석은 AI에 의존한다.
- APK와 서버의 정확한 파일 해시는 [체크섬](../output/checksums.json)에 기록한다. [APK](../output/apk/TapTap-debug.apk), [서버](../output/server/taptap-backend.jar). 검사·패키지는 로컬 산출물이며 Git에 올리지 않는다.

## 실제 연결에 필요한 항목

OpenAI 키는 실제 호출까지 확인했다. Spotify 개발자 앱, Google OAuth 앱/YouTube API 설정, Apple Music 개발자 토큰은 별도다. 비공개 [환경 설정 예제](../backend/.env.example)의 해당 항목과 공개 서버 도메인을 설정한 뒤 실제 허용·가져오기·후보 검토·전송·재시도·변경 반영을 확인해야 한다. 키는 채팅이나 저장소에 넣지 않는다.

공개 HTTPS 실행·백업 절차는 [배포 안내](deployment.md)에 있다. 도메인·호스팅·플랫폼 계정·실제 Android 휴대폰을 아직 제공받거나 연결하지 않았으며 이 검증을 통과한 것으로 기록하지 않는다.
