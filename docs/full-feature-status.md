# TapTap 기능별 상태

`[x]`는 해당 항목이 구현됐거나 명시한 범위에서 검증됐다는 뜻입니다. `[ ]`는 아직 실행하지 않은 검증입니다.

## 구현 완료

### 1. 자연어 개인화 추천
- [x] OpenAI로 후보 생성, MusicBrainz로 실제 곡 확인
- [x] 좋아요·싫어요 반영, 최대 8곡 카드 탐색, YouTube 재생
- [x] **실연동** · 제이팝·드림 팝 추천과 공식 플레이어 재생 확인

### 2. 앱 내 플레이리스트
- [x] 목록 생성·이름 변경·삭제, 곡 추가·삭제·순서 변경, 일괄 저장
- [x] **에뮬레이터** · 두 기기에서 테스트 계정의 목록·반응 복원 확인

### 3. 외부 플레이리스트 가져오기·이전
- [x] Spotify·YouTube 목록 선택, 곡과 버전 검수, 목적지 비공개 목록 생성, 부분 실패 재시도
- [x] **실연동** · YouTube 비공개 목록 읽기와 인증 갱신 확인
- [x] **모의 응답** · 목적지 목록 생성·곡 추가와 부분 실패 재시도 확인

### 4. 긴 YouTube 영상 변환
- [x] 설명·댓글 시간표 추출, 수동 입력, 곡 검수, 개별 영상 매칭과 저장
- [x] **실연동** · 실제 영상 댓글에서 시간표 추출 후 개별 플레이어 열기 확인

### 5. 대화형 추천 수정
- [x] 이전 조건 이어받기, 곡 유지·제외·교체
- [x] **실연동** · 유지한 곡은 남고 제외한 곡은 빠지는지 확인

### 추가 기능 · 계정과 공유
- [x] 카카오·이메일 로그인, 게스트 시작, 계정별 목록
- [x] 공개 링크, 검색·순위, 신고·차단
- [x] **검증** · 테스트 계정 복원과 공유 흐름 확인. 카카오 탈퇴는 모의 제공자와 테스트 사용자로 확인

## 남은 검증

- [ ] Spotify·YouTube 실계정으로 목적지에 비공개 목록을 만들고 선택한 곡이 추가되는지 확인
- [ ] 실제 Android 휴대폰에서 추천·재생·변환·저장 흐름 확인

## 지원 범위

추천은 검증된 곡을 최대 8곡 표시합니다. 시간표가 없는 영상은 직접 입력할 수 있습니다. 영상의 음원을 분석해 곡을 식별하는 기능은 지원 범위 밖입니다.

화면은 [제품 가이드](implementation.html), 날짜별 검사 근거는 [검증 기록](tests-and-evidence.md)에서 확인할 수 있습니다.
