# 기능별 구현·검증 상태

2026-10-19에 [프로젝트 홈](https://app.notion.com/p/3ea64b5ce98381fb8667dd4908751f10), [명세서](https://app.notion.com/p/3ed64b5ce98380b8b96ad80157bff1dd)와 관련 결정 문서를 다시 확인했다. 최신 확정 요구와 대화에서 사용자가 추가한 기능을 기준으로 구현 품질을 검수한다. Apple Music은 제외한다. 사용자가 명확히 한 이번 범위는 출시할 수 있는 품질의 구현·검수이며 실제 공개 서비스 배포나 스토어 출시는 포함하지 않는다.

아래 현재 구현과 과거 빌드의 검사 기록을 구분한다. [카카오 설정](kakao-login.md), [전체 구현 시각화](implementation.html), [검증 요약](tests-and-evidence.md)은 각 문서에 기록된 날짜·범위와 함께 읽는다. API 키·콜백 설정만으로 실제 제공자 승인이나 전송 성공까지 검증한 것으로 간주하지 않는다.

## 현재 구현

- 자연어 추천: 사용자 요청과 조건, 앱 내부 좋아요 태그로 OpenAI가 조건·실제 곡 후보 최대 12개를 제안한다. MusicBrainz에서 제목·가수·녹음 ID를 확인한 후보만 최대 8곡 추천하고 DB에 보관한다. 기본 40곡으로 추천을 대체하지 않으며 검증 실패·빈 결과는 오류 또는 부족 안내와 명시적 재시도로 처리한다. 가져온 플랫폼 정보·영상 설명·이미지·외부 열기·저장 행동은 AI나 개인화 입력으로 사용하지 않는다.
- 장르·언어: 고정 35종 장르나 고정 언어 목록을 제품의 상한으로 쓰지 않는다. 기존 별칭과 함께 `genre:<slug>`를 지원하며 slug는 영문 소문자·숫자로 시작하는 최대 64자의 영문 소문자·숫자·밑줄·하이픈이다. 긍정·제외 태그 목록은 각각 최대 64개다. 언어는 2~3자 기본 코드와 선택적인 하위 코드로 구성된 최대 35자의 ISO/BCP 계열 문법으로 보관하고 빈 값은 미지정, `none`은 연주곡이다. 코드의 문법 검증과 실제 등록 여부 검증은 다르다. 프랑스어와 일본어 등은 구별하며 언어의 긍정·제외·후속 변경·초기화와 모델의 명시적 다중 언어 해석을 보존한다. 장르명·요청의 작성 언어·가수 국적으로 곡 언어를 정하지 않는다.
- 분류와 검증의 구분: 장르·분위기·언어와 자연어 의미는 모델의 분류이고 MusicBrainz는 녹음의 실재·제목·가수를 확인한다. AI가 제안한 ID나 URL을 그대로 신뢰하지 않는다. 캐시 재분류는 검증된 ID·출처·시각과 저장한 목록 스냅샷을 보존한다. 모든 자연어 요청의 음악적 적합성이나 표지 이미지 권리를 검증했다는 뜻은 아니다.
- 대화·탐색·목록: 조건 유지·교체·제외·초기화, 직접 유지한 곡·임시 제외, 새 AI 요청을 통한 곡 교체를 지원한다. 카드의 스와이프·이전·다음·반응, 실제 이미지·배경색, 초안·화면 재생성 복원, 곡 검색·목록 생성·일괄 저장·이름 변경·삭제·순서·텍스트 공유를 제공한다. 서버 저장·생성 재시도는 같은 작업 ID로 중복을 방지한다.
- 영상 변환: 공식 YouTube 영상 설명을 자동 조회하고 필요하면 직접 붙인 시간표를 사용한다. 시간표의 곡·가수·시각을 검토·수정·제외한 뒤 별도 외부 항목으로 저장한다. 알려진 영상 길이의 종료 시각은 시작 시각으로 허용하지 않으며 길이 미상에서는 6시간 포함 상한을 둔다.
- 플랫폼 가져오기·이전: 연결한 Spotify·YouTube 계정의 본인 소유 목록을 조회·체크 선택하고 원본 행·반복 곡·누락 안내를 보존한다. YouTube의 삭제·비공개·잘못된 영상 ID도 원본 위치가 있는 누락 행으로 기록한다. ID·ISRC·제목·아티스트·버전·길이의 후보를 직접 검토·선택·제외해야 비공개 대상 목록을 만든다. 부분 실패·응답 유실은 같은 작업에서 재개한다. 원격 목록 조회가 잘리거나 누락·불연속 행이 있으면 정상 앞부분이라고 추정해 추가하지 않는다. YouTube Music의 좋아요·자동 생성·추천 목록 전체를 제공하는 것은 아니다.
- OAuth 복귀: 성공은 `status=connected`, 거절은 `status=cancelled&reason=access_denied`, 만료·재사용·세션 불일치는 `status=error&reason=session_expired`로 `taptap://connected`에 복귀한다. 제공자 실패는 `provider_unauthorized`, `provider_forbidden`, `provider_rate_limited`, `provider_unavailable`, `connection_failed` 중 고정 사유만 전달한다. state·인증 코드·토큰·원격 오류 본문은 노출하지 않는다. state 일회성·PKCE·세션 확인을 유지하고 앱은 진행 중인 제공자·서버·계정과 일치하는 복귀만 받아 실제 연결 상태를 다시 조회한다.
- 계정·삭제: 카카오톡/카카오계정 또는 이메일 로그인, 익명 데이터 이어받기, 계정별 서버 목록·반응·즐겨찾기와 기기별 세션을 제공한다. 가입 계정 세션은 발급 후 30일에 만료하며 만료된 세션만 제거한다. 익명 세션에는 같은 자동 만료가 없으며 가입 전에도 본인의 익명 서버 데이터를 삭제할 수 있다. 가입 계정 삭제는 비밀번호 또는 같은 카카오 계정 재인증이 필요하다. 다른 소유자·유효한 다른 세션·기기에만 저장한 목록의 범위를 구분한다.
- 외부 변경·기록·보관: 변경 미리보기 후 명시적 반영, 다른 원본과 직접 저장한 곡 보존, 변환·가져오기·전송 재열기와 기록만 삭제를 제공한다. 플랫폼 상세 정보는 원본 조회 후 30일에 만료하며 수동 수정으로 연장하지 않는다. 연결 해제·계정 삭제 시 토큰·외부 항목·교차 후보·공개 스냅샷의 해당 정보를 정리한다.
- 공개 목록: 선택적 공개·읽기 전용 공유 링크·검색·즐겨찾기·복사·즐겨찾기 수에 따른 순위를 제공한다. 공개 전 현재 게시 규칙 동의, 목록·작성자 신고, 작성자 차단·차단 해제와 별도 운영자 인증의 기각·숨김 API를 구현했다. 신고는 본인당 24시간 새 신고 10건·상세 500자이며 같은 대상은 기존 신고로 처리한다. 차단은 본인의 인증된 앱 조회·상세·복사에 적용하며 이미 복사한 목록이나 비로그인 웹 전체를 삭제하지 않는다. 운영 숨김은 공개 링크에서도 적용하고 같은 원본의 재공개를 제한하며, 작성자 신고는 당시 공개 목록들에 적용한다. 접수 자체가 자동 숨김·처리 완료를 의미하지 않는다. 해당 앱·서버 변경은 아래 최종 로컬 검수에 포함되며 이전 47개 중간 집계와 구분한다.
- 동의·재생: 서버 주소·안내 버전별 개인정보·외부 서비스 처리 동의를 받고 동의 전 서버 작업을 차단한다. 공식 영상 상태에서 정확한 ID·`madeForKids=false`·`embeddable=true`를 확인한 경우만 인앱 공식 플레이어를 연다. 아동용·상태 미상·설정/조회 실패·서버 미연결이면 사용자 확인 후 외부 YouTube로 연결한다. 자동·백그라운드 재생 없이 사용자 동작으로 시작하고 이동·배경 진입에 플레이어를 종료한다. 설정에서 개인정보·삭제·도움말·라이선스·문의·앱 버전을 연다.
- 공개 안내·실행 패키지: 앱 소개·개인정보·계정 삭제 안내와 JAR·APK, PostgreSQL·Caddy HTTPS 실행 설정을 제공한다. `SUPPORT_EMAIL`에 실제 운영자 주소를 설정해야 외부 삭제 요청용 메일 작성 링크가 작동한다. 메일 작성 링크만으로 요청 접수·자동 삭제를 수행하지 않으며 운영자의 소유권 확인이 필요하다. 실제 주소가 없으면 외부 창구 미설정을 안내하고 앱 안의 삭제 경로를 제공한다.

## 제한 시간·동시 작업·요청 상한

MusicBrainz는 최대 12개 후보를 한 검색에 묶고 서버 인스턴스 안에서 요청 간격을 1초 이상 유지한다. 검색 잠금 진입 대기는 최대 2초, 잠금·간격·원격 본문을 포함한 전체 검색은 8초, 원격 요청은 남은 시간 안에서 최대 6초다. OpenAI 응답은 100,000바이트, MusicBrainz 응답은 1,000,000바이트에서 읽기를 제한하고 헤더 이후 본문이 멈춘 경우에도 마감 시간을 적용한다. Android 추천 POST의 응답 대기는 35초이며 다른 서버 요청은 22초다. 시간 초과·대기열 포화는 다른 곡을 만들어 채우지 않는다.

같은 소유자의 제공자 조회·토큰 갱신·연결 해제·계정 로그아웃/삭제를 소유자 잠금으로 조정한다. 잠금은 64개 묶음이라 일부 다른 소유자도 같은 묶음에서 기다릴 수 있다. 전송 실행기는 작업자 2개·예약 대기열 64개이며 동일 소유자의 전송 순서를 보존한다. 실행 예약 포화는 503과 재시도 가능한 상태로 처리한다. 다중 서버 확장에는 DB 쓰기·원격 작업·호출 상한의 분산 조정이 필요하다.

본문은 JSON 파싱·DB·외부 호출 전에 512KiB로 제한하고 초과 요청은 413으로 거절한다. 접속 주소별 상한은 전체 240회/분, 익명 세션 발급 30회/시간, 추천 60회/시간, 가입·로그인 10회/분, 지정된 제공자 작업 20회/분이다. 초과 시 429·`Retry-After`를 반환한다. 주소별 카운터는 프로세스 메모리에 있으므로 재시작 시 초기화되며 다중 서버에는 공유 제한이 필요하다. DB에 보관하는 AI 상한은 기본 사용자당 20회/시간·서버 전체 200회/UTC일이며 실패한 시도도 센다.

## 2026-10-19 최종 로컬 검수

최종 H2 52개 중51통과·실패0·1건너뜀, 전용 PostgreSQL 52개 중52통과·실패0·0건너뜀이다. H2 전용 독립 fixture는 PostgreSQL 설정 실행에서도 H2를 사용한다. 최종 APK의 Android API37 43개·API24 42개는 실패·건너뜀 없이 통과했다. 최종 JAR의 격리 Docker·로컬 HTTPS·재시작·새 DB 백업복원15개와 구성된 비밀/사설파일 검사를 통과했다. 게시 규칙의 실제400 복구, 반복 실패 시 복구 버튼1개 유지, 신고·차단·해제·운영 숨김의 최신 회귀를 포함한다. 세부 범위와 정확한 파일 해시는 [최종 검증 기록](verification.json), [검사 범위](tests-and-evidence.md)를 따른다.

최종 보관 경로는 `output/release-quality/`의 `TapTap-debug.apk`, `TapTap-release-unsigned.apk`, `TapTap-release-unsigned.aab`, `taptap-backend.jar`다. 릴리스 APK/AAB는 업로드 서명 전 검사 파일이다. 기존 포트8080이 사용 중인 `output/server/taptap-backend.jar`는 바꾸지 않았으며 새 최종 JAR 경로와 혼동하지 않는다. 이미지 갤러리는 최신 APK의4개 모의 데이터 화면과 이전10월13일6개 화면을 날짜·해시별로 구분한다.

사용자가 실제 AI 연결 검사를 완료 범위에서 제외했다. 기존 키의 공식401 invalid_api_key 실패 근거를 보존하며 현재 실제 추천 성공을 주장하거나 고정곡으로 대신하지 않는다. 이번 빌드의 실제 제공자 OAuth/전송·실제 휴대폰·실제 공개 배포·스토어 제출도 위의 로컬 검수 성공으로 바꾸어 기록하지 않는다. 검사한 JAR의 H2 런타임은 2.5.252로 고정되어 있다. 설치된 Canvas authoring SDK/React stubs·TypeScript6.0.3의 strict no-emit 및 HTML 동작/데이터 검사는 실행했으며 실제 Canvas 호스트·브라우저 시각 미리보기는 미실행이다.

### 이전 중간 검수

중간 체크포인트2는 서버45개 중 실패0·PostgreSQL 전용1개 건너뜀과 core 통과다. 이후 공개 목록 관리 추가 전 체크포인트는 H2 47개 중46개 통과·1개 건너뜀, 전용 PostgreSQL 설정47개 모두 통과였으며 `output/checks/release-quality/pre-community-backend/{h2,postgresql}/result.json`에 보관한다. 이 중간 집계는 최신 관리 기능의 최종 결과로 쓰지 않는다. 초기 dirty-DB·Android 탭/스크롤·복구 슬롯 진단과 수정 전 결과도 날짜·APK별로 보존했다.

## 실제 서비스 설정과 별도 검증 범위

실제 OpenAI 호출은 위에 기록한 과거 빌드와 요청 범위까지 확인했다. Spotify 개발자 앱·Google OAuth/YouTube API의 설정·승인·할당량은 별도다. 실제 서비스 사용에는 비공개 [환경 설정 예제](../backend/.env.example)의 해당 항목, 서비스 주소와 등록된 콜백을 맞추고 서버를 재시작한다. 앱에서 서버 주소를 바꾸는 서버 설정 적용에는 앱 코드 수정이나 APK 재빌드가 필요하지 않다. 실제 허용·가져오기·후보 검토·전송·재시도·변경 반영 성공은 해당 환경에서 검증해야 하며 로컬 모의 응답 검사로 대신 통과 처리하지 않는다. 키는 채팅이나 저장소에 넣지 않는다.

공개 HTTPS 실행·백업 절차는 [배포 안내](deployment.md)에 있다. 현재 목표에 실제 공개 서비스 배포·스토어 게시를 포함하지 않는다. 실제 공개 도메인·호스팅·운영자 연락처·제공자 승인·실제 Android 휴대폰을 쓰는 검증은 로컬 구현 품질 검사와 구분한다. 설정값만으로 OAuth 승인·할당량·네트워크·외부 서비스 성공까지 보장하거나 검증한 것으로 기록하지 않는다.
