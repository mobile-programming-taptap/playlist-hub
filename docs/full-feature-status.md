# TapTap 기능별 상태

| 기능 | 구현 범위 | 실제 확인 범위 |
| --- | --- | --- |
| 자연어 추천 | OpenAI 후보 생성, MusicBrainz 곡 검증, 앱 안의 좋아요·싫어요 반영, 최대 8곡 카드 | 제이팝·드림 팝 등 실제 요청과 공식 YouTube 플레이어 재생 |
| 앱 목록 | 생성·이름 변경·삭제, 곡 추가·삭제·순서 변경, 일괄 저장 | 두 에뮬레이터에서 테스트 계정의 목록과 반응 복원 |
| 대화형 추천 수정 | 이전 조건 이어받기, 곡 유지·제외·교체 | 실제 요청에서 유지한 곡 보존과 제외한 곡 제거 |
| 영상 변환 | 설명·댓글 시간표 추출, 수동 입력, 곡 검토, 개별 영상 매칭 및 저장 | 실제 댓글 영상에서 추출부터 개별 플레이어 열기까지 확인 |
| 외부 목록 이전 | Spotify·YouTube 목록 선택, 곡 후보 검수, 비공개 목록 생성, 부분 실패 재시도 | 실제 YouTube 목록 읽기와 토큰 갱신 확인. 실제 목적지에 쓰는 전송 검증은 남음 |
| 계정·공유 | 카카오·이메일·게스트, 계정별 목록, 공개 링크·검색·순위·신고·차단 | 계정 복원과 공유 흐름 확인. 카카오 탈퇴는 모의 제공자와 테스트 사용자로 검사 |

시간표가 없는 영상은 직접 시간표를 입력할 수 있습니다. 음원을 분석해 곡을 식별하는 기능은 지원 범위 밖입니다. 추천 곡 수는 사용자 조건과 실제 검증 결과에 따라 8곡보다 적을 수 있습니다. 실기기 검증은 남아 있습니다.

화면과 동작은 [제품 가이드](implementation.html), 날짜별 근거는 [검증 기록](tests-and-evidence.md)에서 확인할 수 있습니다.
