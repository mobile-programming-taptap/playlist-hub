# MVP 최종 검증 · 2026-11-08

이 기록 이후 남은 조건부 항목의 검증과 수정은 [2026-11-09 추가 검증](remaining-mvp-verification.md)에서 확인한다. 아래 내용은 11월 8일 당시 빌드 기준이다.

이번 검증은 실제 AI 추천, 영상 재생, 계정 복원, 실패 복구와 긴 영상 변환을 대상으로 한다. 최신 노션의 명세와 관련 결정 문서를 확인했고, 확정되지 않은 MVP 후보를 완료 요건으로 늘리지 않았다. 사용자는 실기기가 없으므로 가능한 검증을 먼저 진행하도록 했다.

## 실제 서비스로 끝까지 확인한 흐름

- **자연어 추천:** 실제 OpenAI와 MusicBrainz로 제이팝·재즈·케이팝·가사 없는 피아노 요청에서 각각 8곡을 받았다. 드림 팝 요청은 외부 곡 검증 서비스 연결 오류로 한 번 503을 반환했고, 같은 요청을 다시 보내 7곡을 받았다. 고정 곡으로 오류를 숨기지 않았다. 이어서 요청에서 유지한 곡과 제외한 곡의 경계도 확인했다.
- **앱 추천 → 저장 → 다른 기기 복원:** 임시 이메일 계정으로 실제 앱에서 추천·좋아요·싫어요·유지/제외·전체 저장을 수행했다. 사용자 데이터가 없는 별도 에뮬레이터에서 로그인하여 목록과 반응을 읽고 제목을 바꿨다. 첫 기기에서 다시 로그인해 변경 사항을 확인한 뒤 임시 계정과 데이터를 삭제했다. 두 번의 새로운 카카오 실인증을 검증한 결과는 아니다.
- **YouTube 재생:** 실제 추천 곡의 영상 후보를 확인하고 공식 IFrame 플레이어를 열었다. 플레이어가 렌더링된 뒤 한 번의 실제 탭으로 PLAYING 상태와 활성 오디오 출력을 확인했다. 앱을 뒤로 보내면 플레이어가 제거된다. 자동 재생이나 자바스크립트 강제 재생으로 검사를 대체하지 않았다.
- **댓글 시간표 영상 변환:** 제공된 `VtJ_2SbYoIM` 영상의 댓글 시간표를 실제로 가져와 개별 영상 후보를 검색했다. 화면 회전 후 선택·저장하고, 긴 영상의 시간 링크가 아닌 다른 개별 영상 ID인지 확인한 뒤 플레이어를 열었다. 검사 중 생성한 앱 목록과 변환 기록은 삭제했다. 외부 YouTube 목록은 수정하지 않았다.
- **Google 인증 갱신:** 만료된 액세스 토큰 상태에서 실제 비공개 목록 읽기를 수행해 200 응답과 갱신된 유효 상태를 확인했다. 외부 콘텐츠 쓰기는 수행하지 않았다.
- **격리 서버의 실제 앱 통합:** 키가 없는 별도 서버와 임시 DB에서 익명 목록의 회원 계정 이전·로그아웃/재로그인·다른 세션 반응 반영·시간표 수정 및 저장·공개 공유/신고/차단 흐름을 검사했다. 기존 사용자 서버와 DB는 건드리지 않았다.
- **비공개 서버 연결:** 앱에 설정된 Tailscale HTTPS 주소로 Android ApiClient의 실제 `/health` 호출이 성공했다. 사용자가 서버 주소를 입력하지 않는 기본 연결 설정도 검사했다.

## 이번에 수정한 문제

- 실패 안내의 재시도 버튼이 너무 빨리 사라지지 않도록 유지하고, 계정·저장 방식 변경 시 이전 재시도를 제거했다. 이전 콜백을 실행해도 다른 계정이나 로컬 저장소에 쓰지 못하는 검사를 유지했다.
- 로그인한 사용자가 첫 화면에서 게스트로 들어갈 때 등록 계정을 그대로 재사용하던 문제를 수정했다. 새로운 익명 세션을 쓰며 기존 계정 데이터는 삭제하지 않는다. 이미 게스트라면 기존 게스트 세션을 유지한다.
- 개발자 서버 주소 입력창에도 공통 입력 스타일을 적용했다. 플레이어 창을 열 때 WebView가 포커스를 받도록 했다.
- 새로운 재생 API를 처리하지 않던 모의 서버와 오래된 버튼 문구를 검사 코드에서 바로잡았다. 선택·재생 검사는 화면이 안정된 뒤 실제 터치를 한 번 보내도록 했다. 성공 조건이나 데이터 보존 검사는 완화하지 않았다.

## 근거와 검사 범위

실행 로그, 실제 서비스 응답, 최종 파일 식별값과 검사별 결과는 [검증 자료](../output/checks/mvp-acceptance-2026-11-08/)에 보관한다. 자동 UI 검사의 재현성을 위해 애니메이션을 끄고 검사하며, 사용자 에뮬레이터의 원래 설정은 완료 후 복원한다. 최초 실패와 재검사 결과를 구분하여 보관한다.

최종 실행 수치는 같은 폴더의 `verification.json`을 기준으로 한다. Android 전체 검사는 53개 중 46개 통과, 조건부 7개 제외, 실패 0개다. 이 중 별도 실행이 필요한 실제 AI·계정 복원·재생·영상 변환·HTTPS와 격리 서버 흐름은 각각 따로 실행해 통과했다. 키가 없는 카카오 빌드 전용 2개는 현재 키가 있는 빌드에서 실행하지 않았다. 서버 회귀 검사는 72개 중 68개 통과, 실패 0개, 환경별 선택 검사 4개 제외다. 별도 JVM 재시작 후 데이터와 중복 방지 검사도 통과했다. Android core 검사와 lint는 통과했으며 lint 경고 72개는 남아 있다.

## 남은 한계

실제 휴대폰·실제 두 사용자의 서로 다른 외부 네트워크는 확인하지 못했다. Spotify 실계정 전송, 모든 영상의 모든 곡 매칭 정확도, 이번 수정본의 카카오 신규 실로그인은 재검사하지 않았다. 카카오 로그인은 앞선 실제 로그인 성공과 이번 SDK 콜백·계정 분리 회귀 검사를 구분한다.

AI의 곡 수·취향 적합성과 YouTube 지역·임베드 정책은 보장되지 않는다. 이번 드림 팝 첫 요청처럼 외부 서비스 일시 오류가 날 수 있다. 팀 서버는 맥과 Tailscale이 켜져 있어야 사용할 수 있다. 이번 작업은 공개 배포나 스토어 제출을 수행한 결과가 아니다. 이전 릴리스 AAB는 과거 산출물이며 최신 앱으로 다시 빌드했다고 기록하지 않는다.
