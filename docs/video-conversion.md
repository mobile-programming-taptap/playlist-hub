# 긴 영상에서 개별 YouTube 영상 목록 만들기

1. 만들기에서 긴 YouTube 영상 주소를 입력하고 **영상에서 곡 목록 가져오기**를 누릅니다.
2. 설명란에 시간표가 없으면 관련도 순 상위 100개 최상위 댓글에서 시간표를 찾습니다. 답글은 확인하지 않습니다. 최대 6시간 영상·100개 시간표 행을 지원합니다.
3. 곡명·아티스트·시간을 수정하고 포함할 곡을 고릅니다.
4. **개별 YouTube 영상 찾기**를 누릅니다. 5곡씩 검색하므로 남은 곡은 **다음 곡의 후보 찾기**로 이어갑니다. 검토만 할 때 원본 목록을 자동 생성하지 않습니다.
5. 각 곡의 **후보 선택 또는 제외**에서 영상과 버전을 확인합니다. 선택한 영상은 **선택한 YouTube 영상 확인**으로 확인할 수 있습니다. 원본 긴 영상 자체는 후보에서 제외합니다. 없는 곡은 제외하거나 곡 정보를 수정합니다.
6. 모든 곡을 선택·제외한 뒤 **선택한 개별 영상을 내 목록에 저장**을 누릅니다. 원본 시간표 목록과 별도 목록으로 저장되며 재시도해도 곡이 중복되지 않습니다.
7. 내 목록에서 저장한 곡 → **여기서 들어보기**를 누르면 해당 개별 영상의 앱 내 공식 YouTube 플레이어가 열립니다. 재생 버튼은 사용자가 누릅니다.

## 계정 인증

공개 영상 설명·댓글 조회와 곡 후보 검색은 서버의 YOUTUBE_API_KEY를 우선 사용합니다. 연결된 YouTube 계정의 인증이 만료돼도 공개 변환은 계속 사용할 수 있습니다. 서버 키가 없으면 연결된 계정을 사용합니다.

개인 플레이리스트 읽기·외부 서비스 전송은 OAuth 권한이 필요합니다. 만료가 가까우면 갱신하고, 갱신이 거절되면 재연결 안내를 표시합니다. 계정 화면의 **다시 인증하기**로 기존 데이터를 지우지 않고 인증을 다시 진행할 수 있습니다. 서비스에서 철회한 권한을 앱이 임의로 복구할 수는 없습니다.

## 검증 범위

실제 댓글 시간표 영상에서 7곡 추출·7곡 후보, 설명 시간표 영상에서 25곡 추출·24곡 후보를 확인했습니다. 앱에서 댓글 추출 → 후보 검색 → 회전 → 선택 저장 → 개별 영상 플레이어 준비까지 검증했습니다. 후보에는 다른 버전이 섞일 수 있어 자동 확정하지 않습니다. 기존 Google 계정의 실제 재인증을 완료했고, 만료 해제와 개인 플레이리스트 조회 성공을 확인했습니다. 실제 재생 버튼 클릭 후 소리·실기기 재생은 검증하지 않았습니다.
